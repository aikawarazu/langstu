# 用户故事推演（三轮）

> 方法：**第一轮发散穷举 → 第二轮细化核心 → 第三轮自我论证收敛**，最终产出需求清单。
> 配套：`UX-storyline.md`（主线动线 / 透明指标 T1–T10 / 红线 R1–R8）
> 符号：`T#` = 透明指标，`R#` = 体验红线。

# 第二轮 · 细化核心故事

**合并规则**：动线相同的合并（如 C1/C2/C3 只是评分不同，合并为一条）；低频或次要的留到第三轮裁决。60 条 → 27 条核心故事，每条补齐**念头 / 动线 / 系统必须给 / 验收**。

---

### US-01 第一次打开（A1 A3 A4 A5）
- **念头**："这是什么？要学多久？我能不能坚持？先别让我承诺。"
- **动线**：打开 → 看到一句话说明 + 一张路线图 → 设置（每天多久 / 通常什么时间学）→ 进入今日页，从 L1 开始。
- **系统必须给**：① 一句话说清"这是什么"；② **路线图**：144 课、按每日投入折算出的预计周期（如"每天 45 分钟，约 7 个月学完"）；③ 只问 2 个必要问题，不问目标/水平/兴趣。
- **验收**：5 分钟内完成设置并开始第一课；全程无功能介绍、无引导气泡、无"完善资料"；用户能说出"我要学 144 课，大概 7 个月"。
- **关联**：T1（全局进度）

### US-02 打开就想知道今天做什么（B4 B5 B7）
- **念头**："今天要我做什么？要多久？别让我选，直接开始。"
- **动线**：打开 → 第一屏 → 3 秒内得到答案 → 点唯一主按钮。
- **系统必须给**：老师一句话（今天几件事、共多久）+ 进度环（含分子分母）+ 每项 `已做/总数` + **唯一主按钮写明精确下一步**。
- **验收**：不点任何东西，3 秒内能说出"今天复习 12 张 + 学 L24，约 45 分钟，现在该点'继续：L24 第 3 步'"。屏幕上不存在第二个同等重量的按钮。
- **关联**：T2 T3 T4，R1 R2

### US-03 复习一张卡（C1 C2 C3 C4 C5 C8）
- **念头**："这词哪来的？我点了这个会怎样？还剩几张？"
- **动线**：看卡面 → 自答 → 点显示答案 → 选一档（忘了/模糊/想起/简单）→ 看到"下次：3 天后" → 自动进下一张。
- **系统必须给**：`第几张/共几张` + 进度条；`来自 L23 · 第 2 次见`；**评分档下方直接标出下次间隔**；选完立即反馈"下次：X"再进下一张。
- **验收**：单手 3 次点击完成一张；用户在点之前就知道每档的后果；能说出"还剩 7 张"。
- **关联**：T3 T5 T6，R6

### US-04 复习到一半被打断（C6 B8）
- **念头**："有人叫我，等会儿接着做。"
- **动线**：做到第 5 张被叫走 → 5 分钟后重开 → 主按钮仍写着"继续：复习第 5 张"。
- **系统必须给**：**精确恢复到中断点**；已完成卡片状态不丢。
- **验收**：重开后零思考接上；不损失任何已答记录；无"欢迎回来"弹窗。
- **关联**：R3（界面结构恒定）

### US-05 今天复习太多了（C7 C8）
- **念头**："今天怎么这么多，能做少点吗？"
- **动线**：今日页看到"复习 20 张" → 想减量 → 点"只有 5 分钟"或类似的轻入口 → 只做 5 张 → 其余顺延。
- **系统必须给**：明确的减量入口（不是隐藏在设置里）；减量后**明确告知其余如何处理**（"其余 15 张分摊到后面几天"）；减量后仍算今日完成打卡。
- **验收**：减量后当次负担明显低于正常；用户知道"债怎么还"；不产生"我没完成"的挫败。
- **关联**：T9，R4 R7

### US-06 某个词总记不住（C9 J2）
- **念头**："又忘了。是不是我记性差？怎么又是这个？"
- **动线**：反复遇到某张卡 → 系统识别到"连续 3 次忘了" → 改变呈现方式。
- **系统必须给**：① 主动换呈现（补例句/给词根/拆音节），**而不是机械重复**；② 明确告知"这个词你见过 6 次了，系统会更频繁地安排它" —— 把挫败转化为"系统在处理"的信任。
- **验收**：用户不会连续 3 次看到**完全相同**的卡面；用户知道系统注意到了这个难点。
- **关联**：T5，R7

### US-07 手滑点错评分（C11）
- **念头**："点错了！能改吗？"
- **动线**：误点"忘了" → 想撤销。
- **系统必须给**：评分后**短暂可撤销**（如 3 秒内显示"撤销"，或下一张前的返回上一步）。
- **验收**：误操作可挽回；不因误点导致该卡间隔被错误重置。
- **关联**：R6

### US-08 开始学今天的新课（D1）
- **念头**："今天学什么？"
- **动线**：点主按钮 → 进入当前课 → 看到第 1 步。
- **系统必须给**：课号/标题/中文；五步指示器；**只显示当前步内容**（不一次铺开五步）。
- **验收**：进入即知学第几课、第几步、共几步；不出现"下一课"入口（防跳步）。
- **关联**：T3

### US-09 听力跟不上，想重听（D2 D6）
- **念头**："太快了，没听清，再来一遍。"
- **动线**：点某句 → 播放 → 再点 → 重播；或点慢速。
- **系统必须给**：**逐句可点播**、可重复播放；提供**语速调节**（正常/慢速）；中英对照**可先看中文或先看英文**（默认隐藏中文，避免依赖）。
- **验收**：任意一句可无限次重听；切换语速不改变进度。
- **关联**：T3

### US-10 生词/语法看不懂（D3 D4）
- **念头**："这词什么意思？这段在说什么？"
- **动线**：看生词卡 → 点开释义；看语法 → 看不懂 → 需要更简单的解释。
- **系统必须给**：生词卡可点开（音标/词性/释义/例句）；语法点用"公式 + 一句人话 + 例句"三段式，**不堆术语**。
- **验收**：生词一键看释义；语法讲解不含用户看不懂的语法术语。
- **注释**：一课 8 个生词不要求当堂记全 —— FSRS 会自动把它们**分散到多天**出现，用户不需要一次记住。

### US-11 环境不允许出声（D7 D5）
- **念头**："在地铁上，没法跟读。"
- **动线**：走到"跟读录音"步骤 → 环境不允许 → 需要跳过。
- **系统必须给**：允许**"暂时跳过，稍后补"**（标记为待补，今日完成度不含它），**不允许永久跳过**（五步是最小完整闭环）；补做入口回到今日页。
- **验收**：跳过不产生负罪提示；待补项在今日页明确列出、可随时补。
- **注释**：与 D5"想跳过某一步"区分 —— 想跳过是因为**难**（该回炉，不跳）还是**环境不允许**（可暂缓）。系统只支持后者。

### US-12 一课没学完要中断（D12）
- **念头**："学到第 3 步，得走了。"
- **动线**：中断 → 稍后回来 → 继续第 3 步。
- **系统必须给**：**步骤级断点续学**（不是"课级"）；已完成的步骤状态保留。
- **验收**：中断后重开，主按钮直接指向"第 3 步"，零思考接上。
- **关联**：R3

### US-13 学完想知道学到了什么（D9 D11）
- **念头**："这课我到底学了啥？这些词什么时候会考我？"
- **动线**：走完 5 步 → 看到产出清单 → 回今日页。
- **系统必须给**：**产出清单**（生词 8 / 语法 2 / 句型 3）+ **去向说明**（"已加入复习计划，明天会再见"）。
- **验收**：用户能说出"我这课学了 8 个生词、2 个语法，它们明天会出现在复习里"。
- **关联**：T7

### US-14 断了一天 / 三天回来（E1 E2 E5）
- **念头**："落下了，得补上。但别给我一堆。"
- **动线**：打开 → 老师一句话说明降档方案 → 只做一小批 → 其余分摊。
- **系统必须给**：明确告知"今天只做 8 张，其余 34 张分摊到后面几天"；**当天负担不高于正常一天**。
- **验收**：归来当天任务量 ≤ 正常量；无任何"你欠了/落后了"措辞；用户知道债怎么还。
- **关联**：T9，R4 R7

### US-15 断了一周 / 一个月回来（E3 E4 E6）
- **念头**："全忘了。几百张卡。要么放弃，要么从头来。"
- **动线**：打开 → 系统给出**极小的当天任务** + **一个"重新开始"的选项**。
- **系统必须给**：① 当天只做最小量（5–8 张）；② **主动提供选项**："积压的卡要慢慢消化，也可以从当前这课重新攒一批 —— 你选哪个？"；③ 绝不在首屏显示积压总数。
- **验收**：用户不会因为看到积压数字而退出；能选到"重新开始"的路径；选择后积压不再打扰。
- **关联**：R4 R7（头号留存场景）

### US-16 出差 / 生病（E7 E8）
- **念头**："没网/没时间/没精力。"
- **动线**：几天无法学习 → 回来 → 走 US-14/15 的降级路径。
- **系统必须给**：**离线可用的复习**（文本卡不依赖网络，PWA 已缓存）；回来后自动走降档。
- **验收**：无网时仍能复习已缓存的卡；回来后不堆债。

### US-17 只有 5 分钟（F1 F2）
- **念头**："没时间了，做点什么别断链就行。"
- **动线**：今日页 → 点"只有 5 分钟" → 做 5 张最该复习的 → 完成打卡。
- **系统必须给**：明确的短时入口；做完后**正常算今日完成**（不是"部分完成"）。
- **验收**：5 分钟内走完；系统认可今日已完成；其余任务顺延且告知。
- **关联**：R5

### US-18 今天时间多，想多学（F3）
- **念头**："今天有空，多学点。"
- **动线**：今日任务做完 → 想再加一课。
- **系统必须给**：提供"再学一课"入口，但**系统绝不主动推荐、不推送、不在完成后弹窗**。
- **验收**：加餐只能由用户主动发起；默认状态不出现任何继续学习的诱导。
- **关联**：R8

### US-19 想知道学到哪了 / 还要多久（G1 G2 G9）
- **念头**："我走到哪了？什么时候能学完？"
- **动线**：看今日页底部常驻进度。
- **系统必须给**：`你在 L24 / 共 144 课 · 16%`；课程页给出"已完成 23 课 / 剩余 120 课 / 按当前节奏约 5 个月"。
- **验收**：**无需进入任何二级页面**就能看到全局进度；不需要战报/统计页。
- **关联**：T1

### US-20 想确认今天做完没 / 明天做什么（G5 G6）
- **念头**："今天算完成了吗？明天又要干嘛？"
- **动线**：完成后 → 看到完成态 + 明日预告。
- **系统必须给**：100% 完成态（含用时）；**明日预告**（"明天：复习 8 张 + 学 L25"）。
- **验收**：用户能明确回答"今天做完了吗"；知道明天要做什么，不需要猜。
- **关联**：T8

### US-21 想知道自己学得怎么样（G3 G8）
- **念头**："我到底记住了多少？我的弱点在哪？"
- **动线**：查看进度相关区域。
- **系统必须给**：**只给基于事实、可行动的指标** —— 已学 N 课 / 累计 M 张卡在复习中 / 最近常错的词（列出具体词）。
- **验收**：**不出现"掌握度 74%"这类无法行动的数字**（知道了能做什么？）；每个数字都能对应一个动作。
- **关联**：见第三轮 Q1（本条被重点质疑）

### US-22 换手机 / 清缓存（H1 H2）
- **念头**："进度还在吗？我是不是白学了？"
- **动线**：新设备登录 → 进度自动出现。
- **系统必须给**：**自动云端同步**，本地仅缓存。用户不需要手动备份才安全。
- **验收**：换设备后进度/卡片状态完全一致；清缓存后重新打开数据仍在。
- **注释**：这是信任的底线 —— 数据丢失 = 用户永久流失。

### US-23 没网 / 音频加载失败（H4 H5 H6）
- **念头**："打不开/听不了了。"
- **动线**：断网 → 打开 → 部分功能不可用。
- **系统必须给**：**文本学习路径完全离线可用**（课文/生词/复习卡）；音频不可用时**明确告知原因**并允许继续（不阻塞流程）；外链失效时给"打开原链接"兜底。
- **验收**：断网时仍能完成今日复习；音频失败不卡住流程；失效外链有替代路径。

### US-24 想调整每日量 / 提醒时间（H8 H9 H10）
- **念头**："45 分钟太多了""别早上提醒我""别催我"。
- **动线**：设置里调整。
- **系统必须给**：每日预算可调（30/45/60/90）；提醒时间可调；**推送可完全关闭**。
- **验收**：调整后次日计划立即生效；关闭推送后无任何打扰。

### US-25 想放弃 / 觉得枯燥 / 怀疑有用（I2 I3 I4）
- **念头**："算了，没意思""学这些有用吗"。
- **动线**：打开频率下降 → 系统需要给一个回头的理由。
- **系统必须给**：**不催、不警告、不谈连续天数**（会加剧愧疚）；用**单调递增的事实**给成就感 —— "你已经学完 23 课了"（这个数字只会涨，不会归零）。
- **验收**：无任何基于"中断/失败"的措辞；展示的进度指标单调递增。
- **关联**：R7

### US-26 凌晨学习（J3）
- **念头**："现在算今天还是明天？"
- **动线**：凌晨 1 点学 → 任务归属。
- **系统必须给**：**以次日 4:00 为日界**（凌晨学习仍算"今天"），避免半夜学完还要再学一次。
- **验收**：凌晨 1 点完成的任务计入当天；4:00 后才翻篇。

### US-27 学了但没点完成（J4）
- **念头**："我明明做了，怎么没记录？"
- **动线**：看了课文但没点"完成第 3 步" → 进度未更新。
- **系统必须给**：**行为即记录** —— 只要发生了真实学习行为（播放了句子/翻了词卡/答了卡），就自动标记该步进行中或完成；**不依赖用户手动点"完成"**。
- **验收**：用户不需要记得点"完成"；系统根据实际行为自动推进。
- **注释**：这是 US-02"零决策"的延伸 —— 连"点完成"这个动作都该尽量省掉。

# 第三轮 · 自我论证（红队质疑与收敛）

对第二轮的故事逐条质疑。**核心质疑工具**：真实性 / 频率 / 必要性 / **负担检验** / **透明检验** / 冲突检验。

## Q1：「掌握度」到底该不该给？（US-21）

- **主张**：用户想知道"学得怎么样"，所以给掌握度。
- **质疑**：**"掌握度 74%"这个数字，用户知道了能做什么？** 它无法指导任何行动。更糟的是，它制造焦虑（"怎么才 74%""降了怎么办"）。这是典型的"看起来有用、实际无用"的指标。
- **反例**：用户真正在意的是"我哪些还没掌握"——这是**可行动**的。
- **收敛**：**不做掌握度百分比**。改为基于事实、可行动的反馈：已学 N 课 / 累计 M 张卡在复习中 / 最近常错的词（列具体词）。
- **决策**：掌握度 → **不做**。常错词 → **M1 做**（但要极轻，不单独成页）。

## Q2：「连续天数」该不该给？（US-25 / G4）

- **主张**：连续天数（streak）是强留存机制，Duolingo 靠它。
- **质疑**：**streak 是双刃剑** —— 它激励人，但一旦断链，"连续 30 天"归零会直接催生"反正断了，算了"的放弃。这与红线 R7（无负罪感）**直接冲突**。
- **关键洞察**：**应给用户"只增不减"的进度指标，而不是"会归零"的连续天数。**
- **收敛**：不做连续天数。给"已完成 23 课"（单调递增、永不倒退）。
- **决策**：连续天数 → **明确不做**（即使它是主流做法）。

## Q3：「加餐」会不会破坏"完成后不诱导"？（US-18）

- **主张**：用户有精力时想多学，是正向需求。
- **质疑**：提供加餐，会不会诱导过度学习 → 负担累积 → 放弃？这正是"1→300"的入口。
- **收敛**：加餐**只能由用户主动发起**；系统不推荐、不推送、不在完成页弹窗。入口极轻（一行字）。
- **决策**：加餐 → **做，但被动**（用户找得到，系统不推）。

## Q4：断了一个月，是"接住"还是"让他重来"？（US-15）

- **质疑**：断一个月的积压（几百张卡）无论如何降档都很大。用户心理上已接近"重新开始"。此时强行消化积压 = 逼他放弃。
- **关键洞察**：**此时"重新开始"不是失败，是合理选项。** 系统应主动给出这个出口，而不是只给"还债"一条路。
- **收敛**：断超过 7 天，除降档外**主动提供"从当前课重新攒一批"的选项**，选了就不再被积压打扰。
- **决策**：**做**（这是留存的关键出口，成本不高）。

## Q5：「跳过某一步」该允许吗？（US-11 / D5）

- **质疑**：五步法如果被随意跳过，产出就不完整（比如跳过听写，就少了听写卡）。但完全禁止，用户在地铁上没法跟读怎么办？
- **关键区分**：跳过的动机有两类 ——
  - **因为难**（想逃避）→ 这恰恰是最该练的，**不允许跳**。
  - **因为环境不允许**（地铁上不能出声）→ 合理，**允许"暂时跳过，稍后补"**。
- **收敛**：只支持第二种。且标记为"待补"，在今日页明确列出，不算完成。
- **决策**：**做"暂缓补做"，不做"永久跳过"**。

## Q6：推送会不会变成打扰？（US-24 / I7）

- **质疑**：推送是"保姆"的核心，但打扰会导致关推送甚至卸载。
- **收敛**：**每天最多 1 次**；内容极简（"今天 12 张 + L24，约 45 分钟"）；**断链后绝不推送"你已断更"**（R7）；用户可完全关闭。
- **决策**：**做，但严格限制**。

## Q7：「点了完成」这个动作该不该存在？（US-27）

- **质疑**：如果依赖用户手动点完成，就多了一个决策和一次记忆负担（"我点了吗？"）。既然系统能感知行为（播了句子、翻了卡、答了卡），为什么要用户点？
- **收敛**：**行为即记录** —— 有真实学习行为就自动推进，不要求手动点"完成"。
- **决策**：**做**（这是 R2 零决策的延伸，且能消除"我明明做了"的委屈）。

## Q8：生词一次 8 个，会不会太多？（US-10 / D3）

- **质疑**：一课 8 个生词，用户当堂记不住会挫败。要不要分批教？
- **关键反驳**：**不需要额外设计** —— FSRS 天然会把新学的内容**分散到多天**出现。第一课出现的 8 个词，不会在第二天全部同时考。用户本来就不需要"当堂记全"。
- **收敛**：不做分批。但要**透明告知**"这些词会分散在后面几天出现，不用一次记住"（消除"记不住=失败"的错觉）。
- **决策**：**不做分批**，改为**透明说明**。

## Q9：进度透明会不会变成"压力展示"？（US-19 / T1–T10）

- **质疑**：全局进度"16%"如果学得慢，会不会让人焦虑（"才 16%，还早得很"）？
- **收敛**：全局进度用**绝对数为主**（你在 L24 / 共 144 课），百分比为辅。绝对数是"走了多远"，百分比是"还剩多少"——前者更有成就感。
- **决策**：**做，但以绝对数为主**。

## Q10：第一次使用要不要弹"添加到主屏幕"？（A6）

- **质疑**：第一次就弹安装提示，用户还没感受到价值就要求承诺 → 反感。
- **收敛**：**第 3 次使用时**，由老师一句话轻提示："把我放到手机桌面，早上打开更快。"可忽略，不重复纠缠。
- **决策**：**做，但延迟到第 3 次、且是一句话**。

## Q11：课程页允许"跳课"吗？（J6）

- **质疑**：主线强调"按顺序学不跳课"。但用户好奇后面的内容，完全禁止会显得僵硬。
- **收敛**：课程页**可以浏览后面课文（只读）**，但**不能跳学** —— 只有当前课的"开始学"。理由：跳学会导致前置生词没学、后续课听不懂，反而伤害体验。
- **决策**：**只读浏览，不跳学**。

## Q12：这些故事里，哪些是我的臆想？

- **审视**：`J1 内容有误`、`H7 双端不一致`、`D13 想看视频` —— 频率低或属于 M2 范畴。
- **收敛**：J1（反馈入口）保留一个极轻的"标记错误"；H7 被 US-22 云端同步覆盖（不存在不一致）；D13 外链视频 → **M2**。
- **决策**：臆想/低频的 → **不做或延后**，不占用主线精力。

## M1 明确不做（有理由，不是"以后再说"的托词）

| 不做 | 理由（来自论证） |
|---|---|
| **掌握度 / 统计图表** | Q1：数字无法行动，且制造焦虑 |
| **连续天数（streak）** | Q2：断链归零会催生放弃，与 R7 冲突；改用单调递增的"已完成 N 课" |
| **战报 / 日报周报** | 进度由 T1–T10 直接满足，报表是重复建设 |
| **错词本（独立页面）** | 常错词并入今日页，不单独成页 |
| **弱项回炉 / 自适应** | 优化层，主线未稳 |
| **永久跳过步骤** | Q5：区分动机，只允许"暂缓补做" |
| **跳课 / 选课学** | Q11：跳学会导致后续听不懂 |
| **生词分批教学** | Q8：FSRS 天然分散，不需额外设计 |
| **系统主动推荐加餐** | Q3 / R8：只能用户主动 |
| **外链视频（胶学等）** | M2，主线未稳 |
| **Anki 导出** | 系统内复习已满足 |

## 关键设计决策（从论证中新产生的，不在初版文档里）

1. **只给"单调递增"的进度指标**（已完成 N 课），拒绝"会归零"的连续天数。← Q2
2. **断超 7 天主动提供"重新开始"选项**，而不是只给还债一条路。← Q4
3. **行为即记录**，取消手动"点完成"。← Q7
4. **绝对数为主、百分比为辅**呈现全局进度。← Q9
5. **日界为次日 4:00**，避免凌晨学习被割裂。← US-26
6. **卡连错 3 次主动换呈现 + 告知**，把挫败转为对系统的信任。← US-06
7. **生词不要求当堂记全**，透明说明"会分散到后面几天"。← Q8
