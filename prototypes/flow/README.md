# 学习助手 · 10 页交互原型（PROTOTYPE）

本目录是一次性原型：回答「这 10 个页面 / 4 套风格，方向对不对」之后，会被正式 React 前端吸收或删除。

## 运行

```bash
cd prototypes/learning-assistant-v1
python3 -m http.server 8137
# 打开 http://127.0.0.1:8137/?theme=warm#/today
```

风格切换：URL 参数 `?theme=warm|clean|dark|retro`，或在页面右上角色板按钮切换。

## 10 页流程（全部可点击）

1. 今日（每日任务包 + 打卡）
2. 课程地图（NCE1 · 144 课 · 里程碑）
3. 课详情聚合页（本课五步 + 资源绑定）
4. 课文精听（点读 / 盲听 / 音频条）
5. 本课生词（翻转卡打分）
6. 语法讲解（公式 + 例句 + 易错 + 关联回溯）
7. 复习（FSRS 卡组打分）
8. 学情报告（日/周 + 错词本 + 掌握度）
9. 老师来信（敦促 / 战报 / 里程碑）
10. 设置 + 「我的」入口（偏好 / 主题 / 数据）

演示数据为示例（NCE1 L23 课文为演示选段，正式版由内容导入器从 nce.ichochy.com 获取）。
